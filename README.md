# 🎨 Modern CSS Layouts & Frontend UI Practice

A hands-on practice repository demonstrating core and modern CSS techniques including Flexbox, CSS Grid layouts, custom UI cards, buttons, and responsive design patterns.

---

## ✨ What's Covered
- **CSS Flexbox:** Alignment, justify content, direction, and flexible wrapping.
- **CSS Grid:** Multi-column responsive grids and template areas.
- **UI Components:** Custom buttons, cards, hover animations, and box shadows.
- **Responsive Design:** Media queries for clean cross-device compatibility.

---

## 🛠️ Tech Stack
- **HTML5:** Semantic layout structure
- **CSS3:** Flexbox, Grid, keyframes, transitions, and modern CSS properties

---

## 🚀 Getting Started
```bash
git clone https://github.com/mkalsariya9127/HTML-CSS.git
```
Open `index.html` in any web browser.
